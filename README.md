Personal Portfolio Landing Page

Overview

A responsive personal portfolio website showcasing my introduction, skills, projects, and contact information.

Features

- Personal introduction
- About section
- Skills section
- Projects section
- Contact information
- Responsive design for mobile and desktop devices

Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries

Project Requirements

- Semantic HTML5 structure
- CSS Flexbox and Grid layouts
- Mobile-responsive viewport design

Design Decision

I chose a clean and responsive layout using Flexbox and Grid so that the portfolio is organized and easy to use on both desktop and mobile devices.
