# Personal Portfolio Landing Page

## Overview
A responsive one-page personal portfolio website designed to showcase personal information, skills, projects, and contact links in a clean and organized layout.

## Features
- Personal introduction
- About section
- Skills section
- Projects section
- Contact information and social links
- Responsive design for desktop, tablet, and mobile devices

## Technologies Used
- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries

## Project Requirements
- Semantic HTML5 structure
- CSS Flexbox and Grid layouts
- Mobile-responsive viewport design

## Project Structure

```text
personal-portfolio/
├── index.html
├── style.css
└── script.js
```

## How to Run
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. The portfolio will be displayed as a responsive web page.

## Design Decision
I chose a clean and responsive layout using Flexbox and Grid so that the portfolio remains organized and easy to navigate on both desktop and mobile devices.

## Learning Outcomes
Through this project, I learned how to:
- Structure webpages using semantic HTML5.
- Create layouts using Flexbox and CSS Grid.
- Apply responsive design using media queries.
- Organize and publish a simple personal website.
